# Banco de Dados II — Biblioteca

A atividade consiste na criação de um banco de dados relacional para representar o funcionamento de uma biblioteca, utilizando MySQL e SQL.

## Sobre a atividade

O banco foi desenvolvido para organizar informações de livros, autores, categorias, editoras, exemplares físicos, usuários e empréstimos.

A estrutura permite simular operações comuns de uma biblioteca, como cadastro de livros e leitores, controle de exemplares, registro de empréstimos, devoluções, atrasos e multas.


## O que foi desenvolvido

Durante a atividade foram aplicados conceitos de banco de dados relacionais, incluindo:

- Criação e gerenciamento de banco de dados com MySQL
- Criação e organização de tabelas
- Chaves primárias e estrangeiras
- Relacionamentos entre tabelas
- Relacionamento muitos-para-muitos (N:N)
- Tabelas associativas
- Integridade referencial
- Restrições `NOT NULL`, `UNIQUE` e `CHECK`
- Valores padrão com `DEFAULT`
- Inserção de dados utilizando `INSERT INTO`
- Consultas utilizando `SELECT`
- Organização e relacionamento de informações

## Possibilidades de uso

A partir deste banco de dados, seria possível desenvolver uma aplicação de gerenciamento de biblioteca com funcionalidades como:

- Cadastro e consulta de livros
- Cadastro de autores e editoras
- Organização dos livros por categorias
- Controle de exemplares físicos
- Cadastro de leitores
- Registro de empréstimos e devoluções
- Controle de livros disponíveis e emprestados
- Identificação de empréstimos atrasados
- Registro de multas
- Consultas e relatórios sobre os dados armazenados

## Conhecimentos adquiridos

O desenvolvimento desta atividade permitiu praticar a criação de uma estrutura de banco de dados pensando em um cenário próximo de uma aplicação real.

Além da utilização dos comandos SQL, a atividade envolveu a definição dos relacionamentos entre as informações e a aplicação de regras para manter a consistência e a integridade dos dados.
